# ⚖️ CalcolaIMC

Un calcolatore interattivo dell'Indice di Massa Corporea (IMC), realizzato come sito web.

🔗 [Vai al sito live](https://calcolaimc.pages.dev/)

## Cos'è l'IMC?

L'Indice di Massa Corporea (IMC, o BMI in inglese) è un parametro biometrico utilizzato per valutare il peso di una persona in relazione alla sua statura. Si ottiene dividendo la massa corporea (espressa in chilogrammi) per il quadrato dell'altezza (espressa in metri).

Il valore risultante permette di inquadrare rapidamente la propria situazione di peso all'interno delle fasce di riferimento standard.
